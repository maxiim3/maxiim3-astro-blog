Let's explore React's most used and basic hook: `useState`.

## What is a state?

**React** uses **Virtual-Dom** to update the UI with a process called **reconciliation** and **diffs**.
In order to notify React there is an update, we must use the API provided by the Meta team.
The state is a value tracked by React internally. It differs from how **Vuejs** or **Svelte** are tracking state.

## State declaration

`useState` is a function that takes an optional argument, the **initializer** and it returns an array _(used as a tuple)_. A **good practice** is to destructure the array into `[state, setState]`.

```tsx
const [state, setState] = useState();
```

The first value is the **actual state value**. The second one is the **function** used to **update the state**.

Note that we can _- and should -_ name the state in a way that _meaningfully_ reflects the context.
For example, for a state representing everyone's favorite state `count`, we can also pass an **initial value** of `0`.

```tsx
const [count, setCount] = useState(0);
// state = 0
```

> **tl;dr**: `useState` returns a tuple containing the state value and its update function.

## Updating the state

So why can't we update `state` directly ?

Even if we set the state to a mutable variable with `let`, we cannot update the state directly.
That's because `count` is a **state value** that can only be updated through its corresponding update function `setCount`.

In order to illustrate, the code below won't work:

---

<WrongCounter client:only="react" />

```tsx
export function WrongCounter() {
  let [count, setCount] = useState(0);

  return (
    <>
      <button onClick={() => (count += 1)}>Increment count</button>
      <p>Count will stay {count} </p>
    </>
  );
}
```

Here is how to update the state correctly:
We can also use a `callback` inside the setter in order to access the current state:

```tsx
setCount(count + 1);
setCount((prevCount) => prevCount + 1); // Same thing
```

Remember, `count` is a value, not a setter. Using `useState(count++)` is not recommended as it bypasses React's state management.

We can add a reset button as well to our example:

<Counter client:only="react" />

```tsx
export function Counter() {
  const [count, setCount] = useState(0);

  return (
    <>
      <button onClick={() => setCount(count + 1)}>Increment count</button>
      <button disabled={count === 0} onClick={() => setCount(0)}>
        Reset count
      </button>
      <p>Count updates {count} </p>
    </>
  );
}
```

> **tl;dr**: Always use the update function to modify state values.
