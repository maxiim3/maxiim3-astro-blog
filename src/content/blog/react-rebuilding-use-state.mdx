## What is a Virtual Dom ?

The useState method is coupled to the Virtual Dom used by React.
Vue.js uses a virtual DOM as well but it handles the state using mostly proxies.

On the other side we cannot reproduce a useState behavior **without** actually mocking a virtual dom.

## What the hell s the diffing and reconcilliation ?

On first load, React will take your code and create a virtual copy of the actual DOM.
